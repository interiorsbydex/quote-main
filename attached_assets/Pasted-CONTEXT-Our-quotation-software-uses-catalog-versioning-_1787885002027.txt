CONTEXT: Our quotation software uses catalog versioning — each project/quote is locked to the catalog version (Google Sheet tab set) it was created under. When Admin adds a brand-new line item/product, it currently only gets added to one version's Google Sheet tab, so it never becomes available to existing projects created under a different (older) version. This is expected for price changes, but NOT expected when Admin is introducing a genuinely new product that should be usable across multiple versions.

OBJECTIVE: Build an Admin feature called "Add New Product" that lets Admin define a new line item once (name, description, unit, image, etc.) and select one or more catalog versions it should be added to (e.g., checkboxes for v1, v2, v3). For each selected version, Admin enters that version's specific price for the item. On save, the system writes this new item as a new row into each selected version's corresponding Google Sheet tab automatically, so the item becomes available to both new and existing projects/quotes on those versions after the next sync.

SCOPE: Only the Admin-side "add new product" flow and the Google Sheet write/sync logic for adding rows to specific tabs. Do not touch pricing calculation logic, discount logic, GST calculation, or the existing per-version catalog read logic used when generating quotes — that already works correctly and must not change.

CONSTRAINTS: 
- Do not change how an existing project reads its assigned version's catalog — a project must still only see items belonging to its own version(s), except for the newly distributed item which will now correctly exist in that version's tab.
- Do not touch or overwrite any existing rows/items in any version's tab — this feature only adds new rows, never edits or deletes existing ones.
- Before writing code, show me the exact list of Google Sheet tabs that represent each catalog version, and confirm the row/column structure so the new item is added in the correct format.

DONE WHEN: I can add one new product from the Admin screen, select 2 version checkboxes (e.g., v1 and v2) with a different price for each, hit save/sync, and then confirm the new item appears as a selectable line item in both an OLD existing project (v1) and a NEW project (v2) — with the correct price for each — without any other existing line item, price, or project being affected.

Test this on one real existing old-version project and one new-version project before confirming it's done.
