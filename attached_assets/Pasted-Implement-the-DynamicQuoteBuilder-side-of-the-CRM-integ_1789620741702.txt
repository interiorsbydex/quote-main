  leadId, pid, clientName, phone, email, projectType, scope, location, estimatedValue
- DynamicQuoteBuilder already reads clientName, pid, projectType, scope, location, estimatedValue, and leadId.
- It does not currently read phone or email.
- It reads several values but does not persist leadId, scope, location, or estimatedValue when it creates a project.
- A DynamicQuoteBuilder project has:
  - id: immutable UUID
  - pid: business-facing PID
- Treat these as separate identifiers:
  - projectId = DynamicQuoteBuilder project UUID
  - pid = business PID
- Do not ever treat a project UUID as a PID.
